# Sample test applications and labels

These files are prototype test data for the AI-Powered Alcohol Label Verification App.

The PDF packets are TTB F 5100.31-style test forms based on the official form fields, but they are not official submissions and are not approved COLAs.

Official blank form reference: https://www.ttb.gov/system/files/images/pdfs/forms/f510031.pdf

Batch CSV: `sample_application.csv`

Application PDFs and structured single-label files are in `applications/`.

Matching label images are in `labels/`.
